# Spectrum

A personal thought archive. **Seven colours. Seven perspectives. One observer.**

Live at **[spectrum.lifeofakhil.com](https://spectrum.lifeofakhil.com)**

Built and maintained by Akhil C Kuriakose (aided also by Jephin Jose) as a long-term legacy project.

---

## Files

- **`index.html`** — the engine (layout, styling, the flower, page logic). Rarely edited.
- **`thoughts.js`** — the content. Edit *only this file* to add a new thought.
- **`CNAME`** — connects the custom domain. Do not delete.
- **`README.md`** — this file.
- **`WORKFLOW.md`** — details the workflow to add posts and some pointers for future enhancements.

## Adding a thought

Open `thoughts.js`, copy the template at the bottom, paste it at the top, fill it in,
and commit. The site goes live in about a minute.
